# Markdown Viewer

Windows向けの軽量・高速なローカルMarkdownビューアデスクトップアプリケーションです。Tauri (Rust) と React (Vite / TypeScript) で構築されています。

## 主な機能

- **ファイルのクイックオープン (`Ctrl + P`)**: `Ctrl + P` でVS Codeライクなファイル検索モーダルを画面中央上部にポップアップ表示。開いているワークスペース（フォルダ）内の全Markdownファイルをインクリメンタル（あいまい）検索し、`Enter` で即座にアクティブペインに表示（既存タブがあれば自動切り替え）。`↑` / `↓` で候補移動、`Esc` で閉じるキーボード操作に対応。全文インデックスは作らず、ディレクトリメタデータのみを走査する超軽量・極小フットプリント設計。
- **コードブロックの軽量シンタックスハイライト**: Markdown内のコードブロックに構文強調表示を適用。フロントエンドに巨大なJSライブラリ（Monacoや全言語入りのHighlight.js等）を持ち込まず、Rust側（`syntect` クレートの純Rustパース）でMarkdown解析時にCSSクラスを付与する低リソース設計。ダークテーマ・ライトテーマ両方に最適化されたGitHubスタイル配色、言語名バッジ、ワンクリックコピーボタンを搭載。
- **開いているファイルの自動リロード（ホットリフレッシュ）**: VS Codeやメモ帳などの外部エディタでファイルが保存された際、自動的に再読み込みして最新のMarkdownを表示。フォルダ全体の常時監視ではなく各ペインで表示中のアクティブファイルのみをRustバックエンド（`notify`）でピンポイント監視する低リソース設計。アトミック保存対応およびリロード前のスクロール位置保持を実現。
- **ページ内テキスト検索 (`Ctrl + F`)**: `Ctrl + F` でアクティブなペイン上に軽量なフローティング検索バーを表示。キーワードに一致するテキストをハイライトし、「前へ」「次へ」ボタンおよび `Enter` / `Shift + Enter` でマッチ箇所へスムーズスクロール可能。総件数と現在インデックス（例: `2 / 15`）の表示、`Esc` によるハイライト解除・バー終了に対応。外部ライブラリを使わない軽量DOM操作。
- **コードブロックのワンクリックコピー**: 各コードブロックヘッダーに配置されたコピーボタンからワンクリックでクリップボードへコードをコピーし、視覚的なフィードバック（「コピー完了」チェック表示）を提供。
- **印刷 / PDFエクスポート対応**: ツールバーの印刷ボタンまたは `Ctrl+Shift+P` からブラウザの印刷・PDF出力ダイアログを起動。ツールバーやサイドバー等のUIを自動的に非表示にし、Markdown本文を用紙（A4等）に最適化して出力可能。
- **目次（TOC / アウトライン）パネル**: サイドバーに「目次」タブを追加。ドキュメント内の見出し（H1〜H6）を高速走査・階層構造で表示し、クリックで該当見出しへスムーズスクロール。スクロール位置に応じた現在地ハイライトにも対応。
- **マルチペイン分割表示**: 画面を最大3ペインまで分割し、複数のMarkdownドキュメントを並行して比較・閲覧可能。ペイン間のタブドラッグ＆ドロップ、空ペインの自動終了設定にも対応。
- **タブ管理 & 閉じたタブの復元**: 複数のMarkdownファイルをタブで管理。タブの切り替え・ドラッグ並び替え、および `Ctrl+Shift+T` による閉じたタブの復元に対応。
- **キーボードショートカット**: 
  - `Ctrl+P`: ファイルのクイックオープン（検索モーダル）
  - `Ctrl+F`: ページ内テキスト検索バーの表示（`Esc` で解除）
  - `Ctrl+O`: ファイルを開くダイアログ
  - `Ctrl+Shift+P`: 印刷 / PDF保存
  - `Ctrl+W`: アクティブタブを閉じる
  - `Ctrl+Shift+T`: 最後に閉じたタブを復元
  - `Ctrl+Tab` / `Ctrl+PageDown`: 次のタブへ切り替え
  - `Ctrl+Shift+Tab` / `Ctrl+PageUp`: 前のタブへ切り替え
  - `Ctrl+1`〜`9`: 指定番号のタブへジャンプ（`Ctrl+9` で最後のタブ）
  - `Ctrl+B`: サイドバーの開閉
  - `Ctrl+,`: 設定画面の表示
  - `F11`: 全画面表示の切り替え（`Esc` で解除）
- **高速Rustパース & 画像バイナリ配信**: `pulldown-cmark` による高速Markdownパースと、バイナリストリーミングによるローカル画像表示の最適化。
- **VS Code風エクスプローラー**: 「フォルダを開く」ボタンからフォルダを選択し、サイドバーにファイルツリーを表示。フォルダの開閉展開やMarkdownファイルの選択・プレビューが可能。
- **リサイズ・折りたたみ可能なサイドバー**: サイドバーの幅調整やトグル表示、一括折りたたみ、更新ボタンを搭載。
- **Markdown表示 & セキュリティ**: GitHubスタイルの読みやすいデザイン（`github-markdown-css`）で描画。`DOMPurify` によるサニタイズ処理を実施し、悪意あるスクリプトや不正HTMLを無害化して安全に表示。
- **表（テーブル）表示対応**: GitHub Flavored Markdown (GFM) 形式のテーブル記法（ヘッダー、区切り線、アライメント指定など）をHTMLテーブルとして美しく描画。
- **画像（Image）表示対応**: Markdown記法（`![alt](path)`）による画像埋め込みに対応。
  - **Web上の画像 (`https://...`, `http://...`)**: 自動読み込み・表示。
  - **ローカル画像 (相対パス `./images/fig.png`, `../assets/pic.jpg`, 絶対パス `C:\...`)**: Tauriバックエンドを介して安全に読み込み表示（日本語パス・URLエンコードにも対応）。
  - **フォールバック表示**: 読み込みエラー時やパスが見つからない場合に分かりやすい代替表示カードを提供。
- **表示テーマ設定（ライト / ダーク / システム連動）**: ツールバーの設定（⚙️）ボタンから、Markdown表示部分のカラーテーマを「ライトモード」「ダークモード」「システム設定に連動」から自由に選択可能。設定内容は自動でローカル保存・維持。
- **リンククリック対応**:
  - **外部Webリンク (`https://...`, `mailto:...`)**: OS既定のWebブラウザで開く。
  - **別Markdownファイルへのリンク (`./sub.md`, `../doc.md`)**: アプリ内で自動的に読み込んで切り替え表示（見出し指定 `#section` も対応）。
  - **同一ドキュメント内の見出しアンカー (`#見出し`)**: 該当見出し位置へスムーズスクロール。
  - **外部ファイルへのリンク (`.pdf`, `.png` 等)**: OS既定のアプリケーションで起動。
- **ドラッグ＆ドロップ (D&D) 対応**: エクスプローラー等から `.md` / `.markdown` ファイルをアプリウィンドウや指定ペインに直接ドラッグ＆ドロップして即座に表示。
- **ファイル選択ダイアログ**: 「ファイルを開く」ボタンから単一ファイルを選択して直接読み込み可能。
- **タイトルバー連動**: 開いたファイル名に合わせてウィンドウタイトルおよびドキュメントタイトルが「`ファイル名 - フォルダ名 - Markdown Viewer`」に自動更新。
- **視覚的フィードバック**: ファイルドラッグ時のオーバーレイガイドおよび未選択時の案内メッセージを表示。

## 開発環境の実行

```bash
# 依存関係のインストール
npm install

# フロントエンド単体での開発
npm run dev

# Tauriデスクトップアプリとしての起動
npm run tauri dev
```

## ビルド

```bash
# フロントエンドのビルド
npm run build

# デスクトップアプリのパッケージング
npm run tauri build
```
